Florida Dental Association Design Algorithm

1.Main method.
    1.1 Get the family size.
    1.2 Get the family record info.
    1.3 Print all menu options.
    1.4 Carry out selected menu option.
    1.5 Close program if 'X' is selected.
2. Get Family Size
    2.1 Get family size from input from user.
    2.2 Check if family size is valid.
3. Get Records for Family
    3.1 Get name of family member.
    3.2 Enter upper teeth for family member.
    3.3 Check if teeth are valid (using seperate method).
    3.4 Enter lower teeth for family member.
    3.5 Check if lower teeth are valid (using seperate method).
    3.6 Complete for previously stated number of family members.
4. Display the menu options
    4.1 (P)rint
    4.2 (E)xtract
    4.3 (R)oot
    4.4 e(X)it
5. Print record
    5.1 Print names of the family members
    5.2 Print each tooth with position.
6. Extract Tooth
    6.1 Enter family member name
    6.2 Check if name is valid.
    6.3 Enter tooth layer.
    6.4 Check if layer is valid.
    6.5 Select tooth position
    6.6 Check if tooth position is valid.
7. Calculate Root Canals
    7.1 Designate each tooth type.
    7.2 Figure out how many roots there are.
    7.3 Determine roots through calculations.
